# Sistema de Atendimento Hospitalar 
Triagem de dados implementada em C++

## Integrantes
Thiago Ferreira da Luz [engs-thiagoluz@camporeal.edu.br]

## Como compilar e executar

**Requisitos:** compilador `g++` com suporte a C++17.

```bash
# Compilar (sem warnings)
g++ -std=c++17 -Wall -o atendimento atendimento_template.cpp

# Executar
./atendimento
```
